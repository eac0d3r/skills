# skills

## Summary and purpose

Repository with AI `skills` created or customized by me.

## Structure, organization, and standardization

`skills` are organized in a directory structure to classify and group them by topic. Each skill has its own directory with the implementation (`SKILL.md`) and documentation (`README.md`). Documentation must be clear, detailed, and written in English. Always indicate the invocation type: model-only, user-only, both, or none (disabled).

The repository's `README.md` contains a table with all available `skills`, including the name, description, invocation type, and link to the documentation.
